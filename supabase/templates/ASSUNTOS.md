# Assuntos dos e-mails (Supabase > Authentication > Emails)

| Modelo no Supabase | Assunto | Arquivo |
|---|---|---|
| Confirm sign up | Bem-vindo ao Speed Tag! Finalize seu cadastro. | `confirmar-cadastro.html` |
| Magic link or OTP | Seu acesso ao Speed Tag | `codigo-acesso.html` |
| Reset password | Redefina sua senha do Speed Tag | `recuperar-senha.html` |
| Change email address | Confirme seu novo e-mail no Speed Tag | `trocar-email.html` |
| Invite user | Você foi convidado para o Speed Tag | `convite.html` |
| Reauthentication | Código de confirmação do Speed Tag | `reautenticacao.html` |
